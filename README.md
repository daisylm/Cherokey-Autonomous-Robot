Tthe present project documents the complete development lifecycle of
the autonomous Cherokey 4WD robot, highlighting three distinct operational phases. First,
hardware assembly establishes the electromechanical foundation according to DFRobot
technical documentation. Second, semi-autonomous operation via Bluetooth. Finally, fully
autonomous obstacle avoidance is achieved utilizing ultrasonic sensing and finite state
machine algorithms.

The key challenge was to determine and correct the timing issue in the forward movement
state, which significantly showed navigation stability after parameter adjustment. Using a
structured debugging and modular code strategy ensuring consistent distance detection.
